Aprendizagem mobile

Um app Moodle™ mais leve e com sua marca para estudantes

O MoodleMobile foi criado para organizações que querem uma experiência mobile direta em torno da própria plataforma Moodle™, sem enviar os estudantes para uma identidade genérica de aplicativo.

O app conecta ao Moodle™ usando web services do Moodle, permite que os estudantes entrem com suas credenciais existentes e dá acesso rápido a cursos, notas e informações de perfil. A estrutura do app também inclui visualizações mobile para formatos de curso e recursos de aprendizagem suportados, com tratamento offline para tipos de conteúdo selecionados.

  • Login do estudante usando o fluxo de token do serviço mobile Moodle™.
  • Lista de cursos, páginas de curso, notas e área de perfil.
  • Suporte a login personalizado, ícones, tela inicial e cores do app.
  • Fluxo de download offline para recursos e atividades suportados.
  • Estrutura de notificações push para abrir links ou atividades Moodle™.
